Rebates and credits reduce what you pay. A complete quote shows each one on its own line, so you can see how it changes the out-the-door total.

Some rebates depend on how you pay, such as a rebate that applies only with dealer financing. If you plan to use your own financing, ask the dealer whether each rebate still applies, and get the answer on a revised quote.
